# MrMWSK Reader Studio

A browser-based HTML reading workspace for local documents. Open an HTML file on your device, inspect its detected Urdu, Roman Urdu, and English sections, adjust typography and theme, navigate headings, print to PDF, and download a cleaned copy while keeping the document on your machine.

## Privacy

- Files are processed entirely in the browser.
- No file is uploaded to any server.
- Active scripts, forms, embedded documents, and remote media requests are removed from the preview.
- Only local browser storage is used for saved reading preferences.

## Run

Open `index.html` in a modern browser. No build step, dependency install, or account is required.

## Notes

- Accepts `.html` and `.htm` files up to 15 MB.
- Includes light, sepia, and dark reading themes.
- Offers independent adjustments for Urdu/Roman Urdu and English typography.
- Works as a static single-file app and can be published on GitHub Pages or any static host.
