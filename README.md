# OpenLeaf Reader Studio

A browser-based HTML reading workspace. Open an HTML document locally, inspect its existing Urdu, Roman Urdu, and English sections, adjust reading appearance, navigate headings, print to PDF, and download a cleaned copy.

## Privacy

Files are processed in the browser and are not uploaded by this tool. The preview removes scripts, embedded documents, forms, and remote media requests. This is a reading and language-section filter, not an automatic translation service.

## Run

Open `index.html` in a modern browser. No build step or account is required.
